חיבור לגיליון

איך מכינים את הגיליון והסקריפט? (פעם אחת)
  1. יוצרים גיליון חדש ב-Google Sheets (אפשר לייבא אליו את tv-sheet-template.csv: קובץ ← ייבוא ← העלאה ← "החלפת הגיליון").
  2. בגיליון: תוספים ← Apps Script. מוחקים את מה שכתוב שם, מדביקים את התוכן של Code.gs, ושומרים (💾).
  3. בעורך הסקריפט: הגדרות הפרויקט (⚙) ← מאפייני סקריפט ← הוספה: שם ADMIN_PASSWORD, ערך — הסיסמה שתבחרו.
  4. פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט. "הפעלה בתור": אני. "למי יש גישה": כל אחד. לוחצים "פריסה" ומאשרים את ההרשאות (אם מופיע "Google לא אימתה את האפליקציה" — "מתקדם" ← "מעבר אל…": זה הסקריפט שלכם).
  5. מעתיקים את כתובת אפליקציית האינטרנט (מסתיימת ב-/exec) ומדביקים כאן למעלה.
  6. בטלוויזיה פותחים פעם אחת: limood.org.il/tv/?sheet= ואחריו אותה כתובת. (אחרי ההתחברות יופיע כאן כפתור שמעתיק את הקישור המלא.)

הכל חינמי: הסקריפט רץ בחשבון הגוגל שלכם. הצפייה בלוח פתוחה, אבל לשמור שינויים אפשר רק עם הסיסמה.
